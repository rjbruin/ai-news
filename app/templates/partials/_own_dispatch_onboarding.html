Set up your own Dispatch
What your own Dispatch does

Your own Dispatch is a custom AI-written publication tuned to your interests. An agent reads news sources and writes an edition on a schedule you choose (daily or weekly), instead of you reading everything yourself. It starts out cloned from the System Dispatch's settings, so it works right away — you tune it from there.

Why you need an API key

Reading sources and writing editions uses AI models, and those cost real money per request. This app doesn't charge a subscription fee — instead, your own Dispatch is paid for with your own OpenRouter API key, and you bring your own credit.

Creating an OpenRouter key
  1. Go to openrouter.ai and create an account.
  2. Add some credit (a few dollars goes a long way — an edition costs about $0.50).
  3. Go to openrouter.ai/keys and create a new API key.

Once your Dispatch is set up, paste the key into the API Key section on this page — it'll walk you through it again there.

Sources and topics

Sources (newsletters, RSS/Atom feeds) are a shared pool everyone draws from — no need to set one up if someone already has, though you can add your own once you have an API key. Every story gets tagged against a shared topic taxonomy.

You control how much of each topic shows up in your editions — Complete (full coverage), Highlights (brief mentions), or None — from the Interests section on this page.

Publishing your Dispatch

Once you're happy with it, you can publish your Dispatch from this page — that lists it on the Dispatches directory so other people can follow and read it too (read-only; they can't change your settings or generate editions). Unpublishing later keeps your Dispatch and its editions intact, just off the directory.
